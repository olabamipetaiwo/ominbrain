## TCM: label-only lookup versus the full rule

Key classes: {'continue': 19, 'confirm': 7, 'escalate': 20}. A model that maps the upstream category to an action class but ignores the stated weeks since chemoradiotherapy picks one class for every progressive-disease item: escalate everywhere gives **84.8%**, confirm-first everywhere **56.5%** (n=46). The rule that defines the key (category + timing) gives 100% by construction. Items on which the timing decides (27 progressive-disease items) are where a lookup-only model fails.
