\begin{abstract}
An accuracy drop when an image is removed or swapped is often read as evidence that a multimodal LLM uses the image, but it can also be response sensitivity alone: the answer changes without moving toward what the image supports. We ask when such an intervention measures image dependence rather than mere response sensitivity, and make the test concrete---reading ablation against the answer prior, adding donor-image swaps scored against the donor's key, and requiring a positive control that only the image can answer---on brain-MRI questions from the LUMIERE glioblastoma cohort whose keys have stated origins. For current open models the result is negative. A reference model extracts sequence and lesion side from the image (\vfourEoneOwnAIAGemini{}\% and \vfourEoneOwnLILGemini{}\%, against \vfourEoneTextAIAGemini{}\% and \vfourEoneTextLILGemini{}\% without it) and tracks swapped images, so the tasks are feasible, whereas four open-weight models answer differently with the image yet gain little from it: one image-effect test survives multiplicity correction, and there accuracy stays below the most common key's share and donor tracking is not separable from a random assignment. On a stated management rule none exceeds the best category lookup, and two bf16 reruns, one from a different model family, stay near chance on the control, so the shortfall is not merely a 4-bit serving artifact. A motivating audit finds a slice-based enhancement rule reproduces the expert RANO rating for \vfourConcordantDetPct{}\% of the \vfourDeterminate{} follow-ups on which it applies, so we do not treat those ratings as validated targets. We characterize observable image-dependent behavior, not internal image use; keys are segmentation- or rule-derived and not clinician-validated.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Medical multimodal LLMs are often evaluated by final-answer accuracy, which cannot distinguish image-based reasoning from reliance on textual cues, option patterns, or guessing. Such shortcuts are well documented: models exploit annotation artifacts in natural language inference \citep{gururangan2018annotation}, syntactic heuristics \citep{mccoy2019right}, and unfaithful stated reasoning \citep{turpin2023language}. In chest-radiograph question answering, models can rely on linguistic patterns or irrelevant image regions \citep{nguyen2025localizing}. Image ablation or swapping is informative only when the displayed image contains enough evidence to recover the answer.

We ask when an image intervention measures image dependence rather than merely response sensitivity. An accuracy difference between an image arm and a text-only arm is confounded by the answer prior (a no-image arm that scores below chance inflates it), and an answer that changes when the image is swapped need not move toward the answer the new image supports. We therefore read the ablation together with three additions: reference values for each phase (chance and the most common key); a matched donor swap scored against the donor's key with the no-image prior subtracted; and an audit of whether the key can be recovered from what is displayed, so that answerability is checked rather than assumed. Protocols that perturb the text or the image and report the change in accuracy, such as HEAL-MedVQA \citep{nguyen2025localizing}, address the same concern; we did not run their protocol, so the comparison is by design, not measured, and Section~\ref{sec:results} gives a worked case in which the ablation alone points to image use and the additions do not. We instantiate the questions on the five OmniBrainBench phases \citep{peng2026omnibrainbench} as same-patient chains from the LUMIERE glioblastoma cohort \citep{suter2022lumiere}: anatomical and imaging assessment (AIA), lesion identification and localization (LIL), diagnostic synthesis and causal reasoning (DSCR), prognostic judgment and risk forecasting (PJRF), and therapeutic cycle management (TCM); Figure~\ref{fig:overview} summarizes the design. The chain is an extension that lets us also test whether a model uses stated facts and upstream context in the management step. A motivating audit of the expert RANO ratings found that they cannot be treated as validated targets for the displayed slices (Section~\ref{sec:audit}), which motivates an evaluation with explicit key provenance and fixed controls (Sections~\ref{sec:v4}--\ref{sec:controls}).

The paper makes three contributions:
\begin{itemize}[leftmargin=*, itemsep=2pt, topsep=2pt]
    \item A protocol that keeps three outcomes apart, accuracy benefit, output sensitivity and donor tracking, and reads image ablation against the answer prior, with a worked case (Section~\ref{sec:results}) in which the ablation alone credits Llama-4-Scout with image use on the diagnosis category although its accuracy with the image stays below the most common key's share and its donor gain is not separable from a random donor assignment.
    \item An item set with an explicit origin for each key, built on LUMIERE, and a motivating audit of the expert labels: an enhancement-based rule reproduces the expert RANO category for \vfourConcordantDetPct{}\% of the \vfourDeterminate{} follow-ups on which it is determinate (coverage is reported separately: it is undetermined for \vfourUndetermined{} of \vfourFollowups{}), so we do not treat those ratings as validated targets for the displayed slices; the audit does not show which side is wrong. The released OmniBrainBench groupings do not give same-patient chains (only 2 verifiable cross-phase links among 6,823 questions).
    \item An evaluation of four open-weight models and one reference model under a prespecified control suite. The reference model shows image-dependent performance on sequence and lesion-side questions, whereas the open models are limited and inconsistent; on the diagnosis-category task the most common key covers \vfourMajorityDSCR{}\% of items, so accuracy there is hard to separate from a class prior even for the reference model. As an extension, the chain tests the use of stated facts and upstream context on the management step.
\end{itemize}

\section{Related Work}
\label{sec:related-work}

\paragraph{Shortcuts and faithfulness.} Models can reach correct labels without performing the intended reasoning. Hypothesis-only baselines exploit annotation artifacts in NLI datasets \citep{poliak2018hypothesis,gururangan2018annotation}, models adopt heuristics that fail on HANS \citep{mccoy2019right}, and biased input features can alter chain-of-thought answers without appearing in the stated rationale \citep{turpin2023language}.

\paragraph{Answering without the image.} Visual question-answering models often exploit language priors. \citet{goyal2017making} countered this by pairing questions with images yielding different answers, while \citet{chen2024right} show that many multimodal benchmark items do not require visual content. Similar failures appear in medicine: \citet{yan2025worse} report severe degradation under adversarial diagnostic counterparts, \citet{jin2024hidden} find flawed rationales in 35.5\% of GPT-4V's correct answers, and \citet{nguyen2025localizing} (HEAL-MedVQA) use textual and visual perturbations to localize shortcuts in chest-radiograph QA. We extend this logic to brain-MRI questions and add a donor swap scored against the donor's key (no-image prior subtracted), per-phase reference values, and a key-recoverability audit; we did not run HEAL-MedVQA's protocol, so the difference is one of design. The same-patient chain extends the questions to interventions on supplied clinical facts. UniMod \citep{gu2026unimod} addresses modality imbalance during training by supervising image-only, text-only, and fused predictions separately; we instead evaluate existing models for observable image dependence.

\paragraph{Brain benchmarks and longitudinal data.} OmniBrainBench \citep{peng2026omnibrainbench} contains 6,823 closed-ended brain-imaging questions spanning five clinical phases and 15 modalities. Its supplement describes a patient-level ADNI extension, but we did not evaluate it. LUMIERE \citep{suter2022lumiere} and MU-Glioma-Post \citep{muglioma2025post} provide longitudinal glioma imaging, treatment, and outcome data but no question layer.





\section{Building Chains from LUMIERE}
\label{sec:lumiere}

\paragraph{Why not OmniBrainBench.} A chain needs one patient's phases. We checked whether any image is shared across questions of different phases within a grouped case: of 6,823 closed-ended questions only 2 verifiable cross-phase patient links exist (both in VQA\_RAD, one AIA and one LIL question each), and a second method based on filename identifiers agreed; the counts are lower bounds (Appendix~\ref{sec:app-compat}). Each sub-corpus was built for one task, so a patient is essentially asked one phase-type of question. This is an incompatibility between the released groupings and our evaluation, not a defect in a promise its authors made.

\paragraph{LUMIERE.} LUMIERE \citep{suter2022lumiere} has 91 glioblastoma patients with longitudinal MRI (T1, contrast-enhanced T1, T2, FLAIR), automated segmentations (DeepBraTumIA and HD-GLIO-AUTO; \citealp{suter2022lumiere, kickingereder2019automated}), RANO ratings by one neuroradiologist \citep{wen2010updated}, and overall survival for most patients. Segmentations are automated and were not manually verified; the ratings are expert-assigned.

\subsection{Motivating audit: can an automated rule reproduce the expert ratings from the displayed slices?}
\label{sec:audit}

The natural key for a diagnosis-category question is the expert RANO rating, but whether that rating can be recovered from the displayed slices is untested. We tested it with an automated reproducibility audit: for each first-line follow-up we tracked one enhancing lesion across scans (at each scan, the 3D-connected enhancing component nearest to the largest component of the post-operative baseline), measured it on its own largest axial cross-section, computed the RANO bidimensional product (longest diameter times longest perpendicular diameter) and applied the enhancement criteria (progression: measurable disease at least 25\% above the smallest earlier measurement, the nadir, or measurable disease where the nadir had none; response against the post-operative baseline; measurable means both diameters at least 10 mm). The rule has no new-lesion criterion beyond that. Coverage: of \vfourFollowups{} first-line follow-ups (one per rated, imaged timepoint before any second surgery), \vfourUndetermined{} are undetermined because no measurable enhancing disease exists on the baseline or nadir scan, so the rule abstains on them. Agreement, our primary number, is computed over the \vfourDeterminate{} determinate follow-ups: the rule reproduces the expert category for \vfourConcordant{} (\vfourConcordantDetPct{}\%, Wilson 95\% interval \vfourConcordantDetLo{} to \vfourConcordantDetHi{}\%, and \vfourAuditClusterLo{} to \vfourAuditClusterHi{}\% when the \vfourAuditPatients{} patients are resampled instead; counting the undetermined ones as failures would give \vfourConcordantPct{}\%, which mixes abstention with disagreement). Most of the \vfourDisagree{} disagreements are the rule returning complete response where the expert rated progressive or stable disease. Disagreement can arise from errors in the automated segmentation or in our slice choice and measurement, from a different target lesion or reference scan than the rater's, from differences between our simplified rule and the rater's assessment (which may use T2/FLAIR change, clinical status and steroid dose), or from evidence absent from the displayed slices; this audit does not separate them. LUMIERE documents that one neuroradiologist rated the studies but not what information they used. Our automated product correlates only moderately with the diameters the rater recorded for the target lesion (Spearman \vfourBpRho{} over \vfourBpN{} follow-ups; ours is a median \vfourBpRatio{} times larger), so measurement error is one plausible contributor, although agreement did not differ with size closeness in the subset that could be checked (Appendix~\ref{sec:app-summary}). The audit therefore shows that these ratings cannot be treated as validated targets for the displayed inputs; it does not measure how many of them are unanswerable, which would need qualified reviewers to assess the displayed inputs for a sample of the disagreements.

\subsection{The item set}
\label{sec:v4}

The keys have four different origins (Table~\ref{tab:phases}), and we make no uniform claim that each is a function of what the model sees: AIA is the sequence rendered; LIL and DSCR are derived from automated segmentation masks the model does not see (recoverable from the slices only if the segmentation is right---segmentation-derived targets reviewers have not validated); PJRF is the recorded outcome, scored probabilistically since a future outcome is not a function of the stated facts; and TCM is the output of a stated management rule, testing adherence rather than clinical correctness. All random choices use fixed seeds and never look at model output.

\paragraph{Cohort.} We select one first-line follow-up per patient (rated and imaged before any second surgery, with an imaged post-operative reference scan), in strata defined by the TCM rule class and the DSCR category, with quotas and seed fixed in advance, giving \vfourPatients{} patients (counts by phase and key in Appendix~\ref{sec:app-summary}). Selection used tabular records and segmentation masks only, and progressive-disease follow-ups within 2 weeks of the 12-week window are left out.

\paragraph{Images.} Each image is an atlas-space axial slice, skull-stripped by the dataset authors with HD-BET \citep{isensee2019automated}, at 4$\times$ magnification with a 20\,mm scale bar, in radiological orientation (checked against the affine). Slice levels are those on which the key is computed.

\paragraph{AIA, LIL, DSCR.} AIA is the positive control: its key is the sequence rendered, balanced over four sequences (the most common covers \vfourMajorityAIA{}\% of items), so text alone can reach only chance in expectation. LIL's key is the hemisphere and anterior/posterior half of the largest tumor-core component on the displayed slice; lesions within 10\,mm of a midline, smaller than 100\,mm$^2$ or with under 80\% of their pixels on their centroid's side of the midline are not asked about. DSCR's stem states the RANO enhancement criteria, and its key is the category computed from the bidimensional products.

\paragraph{PJRF.} The prediction time is the follow-up scan and the outcome is death within 52 weeks of it, from the LUMIERE survival record. The model picks one of four probability bins (midpoints .10, .30, .50, .80) and is scored with the Brier score, not by whether it picked a ``correct'' bin. The base rate (Table~\ref{tab:baselines}) reflects our selection, not a population rate. The origin and censoring of the survival time are undocumented (Appendix~\ref{sec:app-handling}), so PJRF is secondary and no other claim in this paper rests on it.

\paragraph{TCM.} LUMIERE records no treatment after chemoradiotherapy, so a documented treatment is not available and the key is a rule-based recommendation, not what was done: non-progressive disease continues adjuvant temozolomide; progressive disease within 12 weeks of completing radiotherapy is confirmed with repeat MRI before any change; later progressive disease prompts a change of therapy. The 12-week window is from the RANO criteria \citep{wen2010updated}; because we cannot assess the radiation field, the rule is a simplification (see Limitations). Radiotherapy dates are not in LUMIERE, so the stem states the weeks since chemoradiotherapy under an assumed standard schedule (ending 10 weeks after surgery). The same diagnosis therefore maps to different actions depending on the stated timing (\vfourTcmConfirm{} repeat-MRI and \vfourTcmEscalate{} change-therapy items among \vfourTcmPdItems{} progressive-disease items), which lets a lookup of the category alone be told apart from use of the timing fact.




\section{Controls and Pre-specified Analysis}
\label{sec:controls}

The analysis plan (hypotheses, margin, correction family and decision rules) was written before any model run; its hash is recorded in the project log, and the file is not externally timestamped. Models are the four open-weight models (MedGemma-4B \citep{sellergren2025medgemma}, Gemma-3-12B and Gemma-3-27B \citep{gemmateam2025gemma3}, Llama-4-Scout; 4-bit, greedy decoding, 800 tokens; unparseable responses score incorrect). Each condition asks one question with a manufactured upstream context, so a phase's effect is not mixed with the model's own earlier answers.

\begin{itemize}[leftmargin=*, itemsep=1pt, topsep=2pt]
    \item \textbf{E1, image effect} (AIA, LIL, DSCR): accuracy with the image minus text only, paired by patient, with a patient-bootstrap interval. The margin is $\pm10$ percentage points, fixed in advance; ``within margin'' requires the whole interval inside it, which at these sample sizes is reachable only when few items differ between the arms. Holm correction over the 12 model-phase tests; other contrasts are descriptive and unadjusted, with exact McNemar tests \citep{mcnemar1947note} and Wilson intervals \citep{wilson1927probable} where a proportion is reported. Because the bootstrap collapses to zero width when every pair is concordant, we also report, post hoc, an add-half interval for the paired difference \citep{agresti2005simple} and the exact $p$. \textbf{AIA is the positive control:} the plan's operational reading rule is that for a model whose unadjusted AIA interval is not above zero, the test has not been shown to detect image use, and E1 on LIL and DSCR supports no conclusion about it.
    \item \textbf{E2, donor tracking}: swap the image for a donor's with a different key (one donor per patient and phase, same number of images); $G=1[\text{swap}=\text{donor key}]-1[\text{text only}=\text{donor key}]$, so the no-image prior is subtracted. The estimand is conditional on the fixed assignment, in which a patient donates to at most two recipients; donor-dependence checks are post hoc (Appendix~\ref{sec:app-summary}).
    \item \textbf{E3, use of stated facts} (TCM): with the true context, move the stated timing across the 12-week window (\emph{flip\_window}) or replace the stated category by one that maps to another action class (\emph{flip\_label}). The registered summary was the share of answers equal to the rule's new answer; because that counts answers that had not changed, we instead report each item's transition relative to the true-context answer (Table~\ref{tab:e3trans}) and take moved over informative items as the rate of interest. A category lookup alone reaches at most \vfourTcmLookupEsc{}\% accuracy (\vfourTcmLookupConf{}\% if it always confirms first) and cannot follow the timing flip.
    \item \textbf{E4, upstream context}: true, randomly wrong (each earlier answer replaced by a seeded random incorrect option) or absent context.
    \item \textbf{E5, PJRF} (secondary; results in Appendix~\ref{sec:app-handling}): Brier score and skill against the leave-one-out base rate, and AUC.
\end{itemize}

We report three observable outcomes separately: accuracy benefit (E1), output sensitivity (the share of items whose answer letter differs between the image and text-only arms, and between the swapped and own image), and correct donor tracking (E2); none observes internal processing. Output sensitivity, the transition tables and the output-handling counts are post hoc, descriptive analyses. The ordinary five-phase chain (own answers as context) is run with and without images as a secondary analysis; each arm regenerates its upstream answers, so later-phase differences are total effects through the chain.

\paragraph{Reference and precision controls.} Three of the four open models did not meet the operational AIA gate (Section~\ref{sec:results}), so we added three post hoc controls, each reported apart from the four-model Holm family and run under the same prompts, temperature 0 and decision rules (tags and digests in Appendix~\ref{sec:app-handling}). (i)~A reference (positive-control) model, Gemini-3.6-Flash (Google API), on E1 and E2; empty API responses are counted and rerun (\vfourCtrlEmpty{} of \vfourCtrlRecords{} records), and, being an API model, it can change without notice. (ii)~A precision control, Gemma-3-27B rerun in bf16 (vLLM, one GPU) on the same conditions; its reading rule, fixed in advance, was that an AIA interval above zero and clearly above the 4-bit model's would attribute part of the gap to quantization and a near-chance result would not, and the serving stack differs from the Ollama runs, so precision and stack are confounded (we draw no conclusion). (iii)~A non-Gemma control, Pixtral-12B (bf16, vLLM), on E1 and E2 for AIA and LIL; its DSCR image conditions are excluded post hoc because the three-image prompt returned empty output for many records (Appendix~\ref{sec:app-handling}).

\paragraph{The reference model reads the image.} Gemini-3.6-Flash identifies the sequence for \vfourEoneOwnAIAGemini{}\% of patients with the image and \vfourEoneTextAIAGemini{}\% without it (difference \vfourEoneDiffAIAGemini{} points, 95\% CI [\vfourEoneLoAIAGemini{}, \vfourEoneHiAIAGemini{}]), and it places the lesion for \vfourEoneOwnLILGemini{}\% against \vfourEoneTextLILGemini{}\%. With the image swapped for a donor's it gives the donor's answer for \vfourEtwoSwapAIAGemini{}\% (AIA) and \vfourEtwoSwapLILGemini{}\% (LIL) of patients (Table~\ref{tab:ctrl}). A model that reads the slices can therefore answer these items, which shows the tasks are feasible; it does not show that every item is valid, nor why a weaker model fails (perception, input handling or training). DSCR is different: the reference model scores \vfourEoneOwnDSCRGemini{}\% with the image and \vfourEoneTextDSCRGemini{}\% without, where the most common key covers \vfourMajorityDSCR{}\% of items, so most of its text-only accuracy is the class prior, and it recovers the key for only \vfourEoneOwnDSCRGemini{}\% of items. DSCR is therefore only partly answerable from the slices---whether from perception, segmentation-derived keys the model does not see, or key error, which we cannot separate---so a null DSCR effect for another model cannot be read as a failure to use the image.

\paragraph{Open models: image effect (E1).} Sequence identification stays between \vfourEoneOwnAIAGemmaTwelve{} and \vfourEoneOwnAIAScout{}\% (chance 25\%), and Table~\ref{tab:e1} gives every cell; Figure~\ref{fig:e1effect} plots the per-model effect with its interval. The operational AIA gate (an unadjusted interval above zero) is met only by Llama-4-Scout, whose gain is small beside the reference model's; MedGemma-4B, Gemma-3-12B and Gemma-3-27B fall below it, so under the plan's reading rule their LIL and DSCR effects support no conclusion. One image-effect test survives Holm correction, Llama-4-Scout on DSCR, but it does not show that the model reads the category from the slices: its accuracy with the image stays below the most common key's share (\vfourMajorityDSCR{}\%), and the gain arises only because its text-only accuracy falls far below that share. The DSCR intervals above zero for MedGemma-4B and Gemma-3-12B do not survive correction and, under the reading rule, cannot be interpreted; on LIL every interval includes zero. A test that does not survive correction is not evidence of no effect: every open-model AIA and LIL interval is wide and none lies inside the $\pm10$-point margin. Each open model's AIA answers concentrate on one sequence (its most frequent answer covers \vfourAiaModalShareLo{} to \vfourAiaModalShareHi{}\% of the \vfourNAIA{} items), the pattern a fixed default with weak image use would produce; we cannot separate that from a failure to perceive the sequence, though every image reaches the model in each pipeline (Appendix~\ref{sec:app-handling}). Accuracy benefit is small, but answers are not insensitive to the image: the image and text-only arms differ for a substantial share of items in every phase (Table~\ref{tab:e1}).

\paragraph{Precision control.} Rerun in bf16, Gemma-3-27B identifies the sequence for \vfourEoneOwnAIAGemmaTwentySevenBf{}\% with the image and \vfourEoneTextAIAGemmaTwentySevenBf{}\% without (against \vfourEoneOwnAIAGemmaTwentySeven{}\% at 4-bit and \vfourEoneOwnAIAGemini{}\% for the reference model; Table~\ref{tab:ctrl}): the interval includes zero and accuracy stays near chance, so the rerun did not restore AIA performance, and it is indistinguishable from text-only on LIL and DSCR too. Precision and serving stack changed together, so we draw no conclusion about quantization. A second bf16/vLLM model from a different family, Pixtral-12B, is likewise near chance on sequence (\vfourEoneOwnAIAPixtral{}\% against \vfourEoneTextAIAPixtral{}\%) and on lesion side, with null donor tracking (its DSCR image arms are excluded; Appendix~\ref{sec:app-handling}). That a non-Gemma bf16 model on a different stack also sits near chance on AIA makes 4-bit Ollama serving an unlikely sole cause of the open models' near-chance sequence identification, though scale and training still differ, so quantization is not isolated.

\paragraph{Open models: donor tracking (E2).} Swapping the image changes a substantial share of AIA and LIL answers (Table~\ref{tab:e2}), but the new answer follows the donor's key with an interval above zero in only two cells: MedGemma-4B on AIA (gain \vfourEtwoGainAIAMedGemma{}; exact $p=\vfourEtwoPAIAMedGemma{}$) and Llama-4-Scout on DSCR (\vfourEtwoGainDSCRScout{}; $p=\vfourEtwoPDSCRScout{}$), the phase in which its accuracy gain also survives correction; under an exploratory Holm correction over the twelve E2 cells (outside the registered family) the two become \vfourEtwoHolmAIAMedGemma{} and \vfourEtwoHolmDSCRScout{}. Both survive resampling by donor and dropping any one donor, but neither is separable from a random assignment of donor keys (permutation $p=\vfourDonorPermAIAMedGemma{}$ and $\vfourDonorPermDSCRScout{}$; Appendix~\ref{sec:app-summary}), so for DSCR we cannot tell donor-specific tracking from a shift that any swapped image would produce. Every other interval includes zero, including both larger models on sequence and all four on lesion side. On sequence and lesion side the open-model gains are far below the reference model's (\vfourEtwoGainAIAGemini{} and \vfourEtwoGainLILGemini{}; Table~\ref{tab:ctrl}).

\paragraph{Worked example: ablation without tracking.} Llama-4-Scout on DSCR is the case in which reading the ablation alone would credit image use. Its image-minus-text difference is the largest and the only one that survives correction (\vfourEoneDiffDSCRScout{} [\vfourEoneLoDSCRScout{}, \vfourEoneHiDSCRScout{}], adjusted $p<.01$). Three further readings, each added by this protocol, change the conclusion. First, its accuracy with the image (\vfourEoneOwnDSCRScout{}\%) stays below the share of the most common key (\vfourMajorityDSCR{}\%), so the image arm does not beat a constant answer. Second, its text-only accuracy is \vfourEoneTextDSCRScout{}\%, far below both the 25\% chance level and the most common key's share, so the difference arises chiefly because the no-image arm scores far below the prior, not because the image arm exceeds it. Third, when the image is swapped for a donor's, its answer follows the donor's key with a gain of \vfourEtwoGainDSCRScout{} [\vfourEtwoLoDSCRScout{}, \vfourEtwoHiDSCRScout{}] over the text-only prior, but a permutation of the donor assignment does not separate that gain from a random assignment ($p=\vfourDonorPermDSCRScout{}$). A method that scored image reliance by the ablation drop, as HEAL-MedVQA does \citep{nguyen2025localizing}, or by whether the answer changes under replacement, as balanced-VQA pairing does \citep{goyal2017making}, would call this image use---the drop is the largest in the study and the answer does change---but reading the drop against the answer prior and the swap against the donor's key does not. The ablation shows response sensitivity to the image, not that the category is read from the slices; the additions are what prevent that reading.

\paragraph{Stated facts and context (E3, E4).} With the true context, TCM accuracy is below the best category-only lookup (\vfourTcmLookupEsc{}\%) for all four open models, though Gemma-3-12B and Gemma-3-27B exceed the confirm-first lookup (\vfourTcmLookupConf{}\%). Accuracy alone does not show which facts a model uses, so we compare each item with itself under the true context (Tables~\ref{tab:e3} and~\ref{tab:e3trans}). Replacing the stated category moves the answer to the rule's new answer for only a minority of informative items in every model (Table~\ref{tab:e3trans}); MedGemma-4B answers the most common class almost regardless, so many of its answers already equalled the new rule answer before the flip, and counting those as following the rule would overstate its use of the stated label. Crossing the 12-week timing window moves the answer most often for Llama-4-Scout, less for Gemma-3-12B, rarely for MedGemma-4B and never for Gemma-3-27B. True upstream context beats no context (interval excluding zero) for MedGemma-4B, Gemma-3-12B and Gemma-3-27B and beats random wrong context on TCM for all four (unadjusted; Table~\ref{tab:e3}); for LIL and DSCR it does not help in any model, and the one interval excluding zero is a loss (Gemma-3-12B on LIL). Stating the management rule in the prompt (post hoc) raises TCM accuracy for Gemma-3-12B, Gemma-3-27B and Llama-4-Scout and leaves MedGemma-4B unchanged, bringing Gemma-3-12B and Gemma-3-27B close to the best lookup but not above it; part of Llama-4-Scout's gain is better-formed output, as it and MedGemma-4B emit invalid JSON for some items (Appendix~\ref{sec:app-handling}).

\paragraph{Chain (secondary).} The ordinary chain (own answers as context) matters only for TCM, through the stated facts above: most image-minus-text differences are small with intervals including zero (uncorrected), the exception being Llama-4-Scout on AIA, which repeats its E1 result. For LIL and DSCR the true context does not help. We do not claim a causal-degradation effect across phases.











\section{Conclusion}
\label{sec:conclusion}

Accuracy on an expert-labeled brain-MRI chain cannot show whether models read the scan when the labels are not validated targets for what is displayed: an automated rule reproduces the expert RANO rating for \vfourConcordantDetPct{}\% of the follow-ups on which it is determinate, and the benchmark we started from did not establish same-patient chains. We build the chain on LUMIERE with a stated origin for each key and fix a control suite in advance (Figure~\ref{fig:overview}). Read this way, a reference model reads the sequence and lesion side from the image, whereas four open-weight models show limited and inconsistent image dependence: only one accuracy gain survives multiplicity correction (and stays below the most common key's share), donor tracking is not separable from a random donor in any case, and none exceeds the best category lookup on the management rule. These results do not identify whether the models use the image internally, or why, and scale, training, serving stack and quantization are not separated from the gap; clinician review of the keys and more than one reference model are the outstanding steps.



\section*{Limitations}
\label{sec:limitations}

\textbf{Clinician review is outstanding.} No clinician has judged whether each question is answerable from the inputs shown or whether each key is right. The LIL and DSCR keys are computed from automated segmentation masks (DeepBraTumIA) that the model does not see, so they are targets that a reader can recover from the slices only if the segmentation is right, and segmentation errors propagate to them. The reference model's results support the feasibility of the AIA and LIL tasks, not the validity of every item. The enhancement rule ignores T2/FLAIR change, clinical status and steroid dose, abstains where no measurable enhancing disease exists (\vfourUndetermined{} of \vfourFollowups{} follow-ups), and reproduces the expert category for \vfourConcordantDetPct{}\% of the determinate ones; disagreement can come from segmentation or measurement error, from a different target lesion or reference scan, from the simplified rule, or from evidence outside the displayed slices, and the audit does not separate these. Consequently our complete response label is weaker than clinical RANO's: it is assigned whenever follow-up enhancement falls below the measurability threshold, which can include residual sub-threshold enhancing disease, not clinical RANO's sustained disappearance of all enhancing and nonmeasurable disease. The rule also tracks a single lesion (the enhancing component nearest the baseline target lesion's location) and has no RANO new-lesion criterion, under which an unequivocal new lesion is itself progressive disease; of the \vfourNewLesionN{} follow-ups where the rule says complete response but the expert rated progressive disease, \vfourNewLesionPlausible{} show a distinct, newly measurable enhancing component elsewhere consistent with a missed new lesion, \vfourNewLesionPreexisting{} show a similarly sized component already present at the nadir, and \vfourNewLesionNone{} show no other measurable enhancing component at all, so this disagreement is not entirely explained by the tracking rule. The expert rating is recorded but is not the key.

\textbf{The management key is a rule, not a documented treatment.} LUMIERE records no treatment after chemoradiotherapy. The TCM key rests on an assumed radiotherapy schedule (ending 10 weeks after surgery) and on a simplified reading of the 12-week RANO window, which also allows progression inside the window when new enhancement lies outside the radiation field. The PJRF outcome assumes that survival time and scan weeks share the surgery-week origin, and censoring is not documented. With \vfourPjrfN{} patients a leave-one-out logistic model on the stated facts did not improve on the base rate (Brier \vfourPjrfBrierLR{} against \vfourPjrfBrierBase{}), which does not show that the facts carry no predictive information; the base rate reflects our stratified selection, and because the outcome construction is unverified PJRF is secondary and supports no claim here.

\textbf{Power and scope.} With \vfourNLIL{} to \vfourNAIA{} patients per phase, the pre-specified $\pm10$-point margin is reachable only when few items differ between arms, and several cells will be inconclusive. Only one E1 image-effect test (Llama-4-Scout on DSCR) survives Holm correction, and three of the four open models (MedGemma-4B, Gemma-3-12B, Gemma-3-27B) fail the plan's own AIA positive-control gate, so under the preregistered rule their LIL and DSCR effects support no conclusion at all, not merely a weak one. The positive control tests one skill, sequence identification; passing it does not show that a model can read lesions. The donor images come from different patients, so anatomy differs beyond the tested feature; stems in the text-only arm still refer to images. Patients are from one center and the cohort was stratified by design; the four open-weight models run at 4-bit through Ollama while the control is an API model of unknown size and precision, so the gap between them mixes scale, quantization and training and cannot be attributed to shortcut learning; bf16 reruns of Gemma-3-27B and of a different-family model, Pixtral-12B (both through vLLM, so precision is confounded with the serving stack), stay near chance on AIA, which makes 4-bit Ollama serving an unlikely sole cause but still cannot isolate quantization from the serving stack, scale or training, and only these two were rerun. There is one reference model, run once at temperature 0, and API models change without notice. \textbf{Input handling was checked only in part.} We confirmed post hoc, for each pipeline, that every image of a question raises the prompt token count (including the second and third DSCR images) and that known-answer probes are answered correctly (Appendix~\ref{sec:app-handling}). We did not compare the images each serving stack passes to its encoder with a reference implementation, and a check on one patient cannot show that MRI contrast is preserved by each model's image encoder. Near-chance sequence identification in several open models therefore remains unexplained: the check makes a dropped-image bug unlikely but does not exclude weak encoder features or default-answer behavior. MedGemma-4B returned invalid JSON for \vfourParseInvalidMedGemma{} of \vfourParseNMedGemma{} records, and Llama-4-Scout for \vfourParseInvalidScout{} of \vfourParseNScout{}; the answer letter was recovered by pattern for all but \vfourParseNoLetterMedGemma{} records (Appendix~\ref{sec:app-handling}). The comparison to the reference model mixes scale, training, quantization and serving. Intervals treat patients as exchangeable.

\section{OmniBrainBench Compatibility Details}
\label{sec:app-compat}

A chain presupposes that a case's phases are one patient's trajectory. In the 6,823-question closed-ended subset of OmniBrainBench \citep{peng2026omnibrainbench} only \textbf{2} verifiable cross-phase patient links exist (both in VQA\_RAD, one AIA and one LIL question); stripping modality, view and slice suffixes from filenames gave the same result. The release has no complete patient identifier, so these are lower bounds. Each sub-corpus was built for one clinical task, so a patient is essentially asked one phase-type of question, and reading \texttt{source\_file} as patient identity would stitch together different patients. This is an incompatibility with our evaluation, not a defect in the benchmark. The supplement's patient-level ADNI extension is not a brain-tumor cohort and, as of September 2026, has label-generation scripts only; we did not evaluate it. We found no dataset with same-patient, multi-phase continuity and a question layer (Section~\ref{sec:related-work}), which motivates LUMIERE.
